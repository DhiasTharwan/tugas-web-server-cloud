Praktikum Komputasi Awan - Web Server on Cloud

Tentang Website

Website ini merupakan hasil pengembangan praktikum Web Server on Cloud menggunakan GitHub dan Vercel. Website telah diperbarui melalui proses Continuous Deployment.

Informasi Praktikum

Mata Kuliah: Komputasi Awan

Materi: Web Server on Cloud

Teknologi: HTML, CSS, GitHub, dan Vercel

Tujuan Deployment

Deployment bertujuan agar website dapat diakses melalui internet. Dengan integrasi GitHub dan Vercel, pembaruan website dapat dilakukan secara otomatis ketika terdapat perubahan pada source code.
