Tentang Website

Website ini dibuat untuk memenuhi tugas praktikum Web Server on Cloud. Halaman dibuat menggunakan HTML dan CSS, kemudian source code disimpan pada GitHub dan dipublikasikan menggunakan Vercel.

Informasi Praktikum

Mata Kuliah Komputasi Awan
Materi Web Server on Cloud
Teknologi HTML, CSS, GitHub, Vercel

Tujuan Deployment

Deployment bertujuan agar website dapat diakses melalui internet tanpa harus dijalankan langsung dari komputer pembuatnya. Integrasi GitHub dengan Vercel juga membantu proses pembaruan website secara otomatis ketika terdapat perubahan pada source code.
